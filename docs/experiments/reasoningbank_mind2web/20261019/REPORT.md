# ReasoningBank Mind2Web 统一底座主对照实验报告

报告日期：2026年10月19日。结果状态：**B组全量完成，无记忆组缺3题；总计2225/2228次评测完成（99.87%）**。当前控制器已结束，状态为 `incomplete`，没有后台补跑。

## 1 实验结论

采用第一轮训练后的冻结经验库，ReasoningBank相对同底座无记忆agent呈现小幅且不一致的增益。完整验证集Step SR提高1.77个百分点，完整Cross-Task提高1.06个百分点；共同完成任务上的Cross-Website下降0.65个百分点，Cross-Domain提高0.74个百分点。不能据此宣称在所有域稳定提升，也未进行多随机种子重复实验或统计显著性检验。

本报告是本项目统一底座下的**B组方法对照**，不是ReasoningBank原论文成绩的直接复现；A组自评持续学习和多模态成绩不包含在本报告中。

## 6 适配与运行修复

1. 统一官方多模态数据快照、Top-50候选、DOM压缩、ID映射、真实历史和算分函数，并记录源码与数据哈希。
2. 区分执行输入与训练反馈；reference_actions仅在B组训练执行后提供。冻结期不学习。
3. 保留ReasoningBank单agent和经验机制，模型及embedding替换、显式经验适用性检查等适配差异写入配置；不能视为原论文原生配置复现。
4. 增加逐步请求/响应、用量、超时、检索、经验库哈希日志；检查thinking开启、输出完整性及长上下文请求。
5. 修复评测从头重试：保存完成动作，基础设施时间窗口耗尽后从下一步继续。复用最早有效轨迹前缀，只接受与此前缀一致的扩展，不按评分选轨迹。
6. 固定第一轮经验库后，分片缺测不再阻塞其他独立评测；全量不足时仍标记incomplete。4→8并发交接保留原工作进程，所有进程共用3秒准入间隔。

旧评测一度因一题18步任务反复耗尽20分钟且从头重跑而整体停止，这属于恢复策略问题。修复后已推进至当前覆盖率；后续确实记录到限流、超时和服务端错误，不能将所有慢请求都归结为单一原因。最新全套自动测试50项通过，之后并发调度相关8项测试通过；本次发布前全套50项测试再次通过。

多模态代码支持当前步截图，但早期实际端点截图识别预检未通过，故本报告只发布纯文本结果。截图接收成功不代表视觉理解有效。
