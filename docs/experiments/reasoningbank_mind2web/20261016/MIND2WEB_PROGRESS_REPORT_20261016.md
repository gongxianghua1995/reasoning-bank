## 各组协议

| 项目 | A组自评持续学习 | B组训练后冻结 | 无记忆对照 |

| 初始经验 | 每个测试域独立空库 | 训练开始为空库 | 始终为空 |
| 训练 | 无预训练，每题一次 | 303题两轮，共606次 | 无 |
| 反馈 | 模型自评，不读官方评分 | 训练后读取任务及逐步评分，不给正确动作或 gold 值 | 无学习反馈 |
| 写库时间 | 每题执行后 | 每批8题全部完成后统一提交 | 不写库 |
| 检索 | 当前题只读此前题目经验 | 同批读取相同快照；第二轮可用第一轮同题经验 | 不检索 |
| 选库 | 无 | 两份轮次快照各跑101题验证，选宏平均 Step SR 较优者，平分选早轮 | 无 |
| 正式测试 | 各域内串行持续更新 | 选定记忆库冻结，只检索 | 独立执行 |

B组两轮是当时对齐 SwarmEvolution 训练组织的配置，不是 ReasoningBank 方法的必要步骤。A组没有第二轮。B组仍保持单 agent、ReasoningBank 经验表示和 top-1 检索，不引入 Swarm 的多角色或经验蒸馏算法；不能宣称全部训练机制与最新 SwarmEvolution 一致。

统一配置：DeepSeek-V4-Flash-0731，动作温度0.7、自评0、提取1，最大输出16384 tokens；BGE-small plain query、cosine top-1；每条经历提取1至3条经验；逐步判断适用性；动作阶段每题1200秒，每步180秒，有界超时恢复。总调度容量8，B训练并发4，A各域内部串行。

当前仍使用原版 Mind2Web：训练303、验证101，Cross-Task252、Cross-Website177、Cross-Domain912。它与后续多模态数据源的测试清单不同。

## 异常与计数口径

采样时 B训练记录18条失败，其中16题动作失败、2题经验提取失败；A三个域分别记录9、5、6条失败；无记忆验证和 Cross-Task 分别记录2、5条失败。日志中已有 API超时、限流及单题预算耗尽。

**失败记录不一定与完整评分互斥。** 例如 B训练463题完整评分中，有2题随后提取失败，因此实际已处理为479，而非463＋18＝481。先前将这两个数的差异解释为在途任务不够准确，本报告以去重后的落盘记录修正。A Cross-Task 同样有评分完成后学习失败的情况。

当前没有阶段级阻塞；单题缺测仍需在收尾时单独处理和报告。B验证按已有队列最多3次补跑缺测，只有完整验证覆盖才进行快照选择；训练和正式测试的异常保留原始记录，不用成功子集冒充全量完成。

运行中的 `usage.json` 当前主要汇总已结束的子任务，不能代表整个队列累计费用。完整用量还需要从所有运行事件归集。
