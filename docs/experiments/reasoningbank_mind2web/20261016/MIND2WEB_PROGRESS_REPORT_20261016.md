### B组官方反馈的内容与使用时机

B组使用官方评分监督经验提取，与 A组自行判断是否成功有明确区别。“不提供正确动作或 gold 值”指不直接展示标准答案，并不表示缺少官方反馈。

| 信息 | A组经验提取 | B组经验提取 |
|---|---|---|
| 当前任务及 agent 实际预测轨迹 | 提供 | 提供 |
| 成功／失败信号 | LLM 自评 | 由官方评分决定；全部步骤正确才使用成功提取分支，否则使用失败分支 |
| 官方任务级反馈 | 不提供 | Step SR 总分、FULL／PARTIAL／NO 状态，以及任务级汇总指标 |
| 官方逐步反馈 | 不提供 | 每步 EA、AF1、Step SR、候选召回及动作格式有效性标记 |
| 标准答案 | 不直接提供 | 不直接提供正确元素 ID、参考动作或正确输入值 |

具体流程为：agent 完成该题预测 → 评分器依据标注计算指标 → 将轨迹和官方反馈一起交给经验提取器 → 批末提交经验。B组不调用 LLM 自评；官方评分在预测结束后才进入提取，不作为该题执行中的提示。验证和测试期间经验库冻结，不进行经验提取或写回。

例如，一步反馈为 EA＝1、AF1＝0、Step SR＝0，提取器可以确定“元素选择正确，但操作或输入值不匹配”，而非凭模型感觉判断整步成功。反馈不会直接告诉它应输入哪个标准字符串，提取器需要结合已有预测与页面证据归纳经验。

2026年10月16日核查实际运行：配置为 `feedback_source: official`；一条12步训练轨迹的官方 Step SR 为7／12，逐步评分确实出现在 `extract_request_1.json` 中；对应 `learning_signal.json` 记录 `source: official`，未生成自评文件。相关记录位于本地 `outputs/mind2web/two_protocols_20261015T085651Z/aligned_train/cases/01_00262395ddb1d67f/`。

当前检查到的 SwarmEvolution Mind2Web 评分接口也向后续诊断提供 `official_score`、`resolved` 和 `action_metrics`，不直接附加参考动作。B组对齐的是这一官方反馈信息层级；经验归纳仍使用 ReasoningBank 的实现。官方评分能够指出哪些预测有误，但不保证提取器归纳出的经验本身完全正确。
