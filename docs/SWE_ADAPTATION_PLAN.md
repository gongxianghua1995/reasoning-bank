2026-10-12 开始。2026-10-13 已完成两题真实解题及官方评分（0/2），并修复、单独补验第二题经验提炼格式错误。原始批次终态仍为 memory_error；修复后未重跑完整两题。详见 [10 月 13 日报告](SWE_SMOKE_20261013.md)。

## 固定范围

- 解题采用仓库自带 mini-swe-agent 1.10.0 的 DefaultAgent，保留 Bash ReAct 循环及原有记忆注入方式。
- 保留官方成功/失败记忆提炼提示、基于当前 issue 检索历史 query 的 top-1 语义检索，以及逐题顺序更新记忆。
- 解题、自评和提炼调用本机 OpenAI 兼容模型服务；embedding 后端单独验证和记录，改变官方 Gemini embedding 时明确标识。
- 生成与评分容器 network=none；只有宿主模型接口可以联网。模型仅收到公开 issue、仓库内容和本批次此前生成的记忆。
- 复用成熟的工作区基线、浅历史、真实 diff 导出及 Verified 评分辅助代码，保留来源；不引入 CAMEL 或 GPTSwarm 团队调度。
- 本次实现 memory=reasoningbank 与 memory=none 开关；不启用 MaTTS，不做多轨迹挑选。
- 每次实验空记忆起步，固定任务顺序；无自动重跑或从旧成绩导入记忆。官方测试结果不会反馈给自评和记忆提炼。

## 运行预算

计划沿用 DeepSeek-V4-Flash-0731、temperature 0.2、单请求最多 16384 输出 tokens、解题 1200 秒。自评和提炼各最多 180 秒，独立计时及 usage，不能将它们隐去后宣称与无记忆实验预算完全相同。命令最多 120 秒，API 最多 300 秒并服从剩余阶段时间。
