2026-10-13 开始。范围：适配单 agent ReasoningBank，并完成真实模型冒烟；不启动全量训练或测试。

## 固定实验协议

- 数据、seed 42 划分、top-50 候选、官方精简 DOM、局部元素 ID 映射与评分复用 agent_evolving 的 swarm-evo-www 分支（当前 b08a5e1559d279ccbaed278d2bfff08e33c6bd38）。不复用其团队或经验学习算法。
- 每个完整 case 包含全部标注步骤，单 Web agent 逐步骤预测 CLICK／TYPE／SELECT。固定快照、之前的人工动作；不连接浏览器、不运行 SWE 容器。
- ReasoningBank 保留任务级 top-1 经验检索、成功／失败 LLM 自评和最多三项经验提炼；使用官方 Web 经验提示，新增离线任务说明。不启用 MaTTS。
- 训练任务结束后写记忆；验证／测试记忆冻结，只检索，禁止提炼与写入。评分仅进入独立报告，不反馈给自评或提炼。此项属于冻结评测适配，不是原论文在线持续学习复现。
- 第一版默认 global 记忆检索，并支持 local 与 none 对照；网站范围变化明确标识。Embedding 沿用本地 BGE-small，属于相对官方 Gemini embedding 的实现差异。
- 使用已有 GPTSwarm/.env 模型服务，密钥不复制到代码或记录。固定实际模型与预算，保存完整请求、模型响应、usage、动作、记忆和来源哈希。
